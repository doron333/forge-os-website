Six-step build path

  1. Define one verifiable outcome
  2. Map the current human process
  3. Choose architecture (default: single constrained agent)
  4. Design role, tools, memory, output
  5. Connect only required tools
  6. Install, measure, iterate

Four layers

Prompt · Context · Harness · Loop
Prompt packs only touch the first layer. Most failures live in the other three.

Failure modes

  • Context drift
  • Silent tool failures
  • Unbounded loops
  • Ghost actions
  • No observability
