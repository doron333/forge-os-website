# Forge OS Website

Official website and content system for Forge OS — The Complete AI Life & Business Operating System.

## Structure

- `/blog` — SEO content published by the Forge Content Operator
- `/agents/content-operator` — Fully automatic multi-stage SEO content agent
- Site files for the main landing and consulting pages

## Automation

The Content Operator is designed to run on a schedule via GitHub Actions.
Once an LLM API key is added as a repository secret, it can research, write, and publish new articles automatically.
