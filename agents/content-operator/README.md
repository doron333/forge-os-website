# Forge Content Operator

Multi-stage AI agent system that researches, outlines, writes, and optimizes SEO content for the Forge OS website (and for customers).

## Pipeline Stages

1. Keyword & Intent Agent
2. Research & Outline Agent
3. Experience-Infused Writing Agent
4. SEO Polish Agent

## Goal

Produce high-quality, experience-based long-form content that ranks and can run on a schedule with minimal human intervention.
